Program A

3Dプリンター体験！ネームプレート作り

頭の中の「つくりたい」を、手に取れる作品へ。スマホのWebアプリで自分だけのネームプレートをデザインし、目の前の3Dプリンターで形にします。

対象（基本）
小学生〜中学生
人数の目安
約10人／回
時間
約60分
分野
ICT・ものづくり
01Flow

体験の流れ

デザインしたものから順に、スタッフが3Dプリンターで造形します。造形は02・03と並行して進めます。

  1. デザインする

    自作のWebアプリ「ZEROモデリング」で、形・文字・書体・配置・色を選び、自分だけのネームプレートをデザインします。

    20分

  2. 仕組みを知ろう

    材料を溶かして1層ずつ積み重ねる仕組みを、実物とスライサー（データを層に分けるソフト）の画面で解説します。造形中のプリンターも間近で見学します。

    20分

  3. 作品紹介と応用例

    希望者が自分の作品を紹介します。医療や建築など、社会で3Dプリンターが使われている例も紹介します。

    15分

  4. 作品を受け取る

    冷めた作品をプリンターから外してお渡しします。時間内に終わらない分は後日お渡しします。受け渡しの方法は事前に決めます。

    当日または後日

全体で約60分の例です。時間は人数とプリンターの台数に合わせて調整します。

02Roles

子どもと講師・スタッフの役割

子ども

  • アプリで形・文字・色を選んで、デザインする
  • 3Dプリンターの仕組みを知る
  • 3Dプリンターの社会での活用例を知る
  • 完成した作品を受け取る

講師・スタッフ

  • 講師（代表 石原）がミニ講義と全体の進行を担当する
  • スタッフがデザインの操作をサポートする
  • スタッフがプリンターを管理し、作品を造形する（子どもは3Dプリンターに触りません）
03App

使うアプリを、スマホで試せます

体験で使う「なまえプレート」のデモ版を公開しています。形・名前・フォント・大きさ・色などを、9つのステップで選んでデザインします。スマートフォンやパソコンのブラウザから、そのまま試せます。

04Option

追加オプション：からくりおもちゃ

3Dプリンターで作った部品を、図解の説明書を見ながら組み立てて色を塗り、動くおもちゃを完成させます。歯車やクランクがどう動きを伝えるのかを、手を動かしながら体験できます。ネームプレートの造形を待つ時間に組み込むこともできます。

メリーゴーランド

ハンドルを回すと、動物たちがくるくる回ります。

観覧車

ハンドルを回すと、観覧車がゆっくり回ります。

時計

歯車がかみ合って、針と鳥が動きます。

魚

ハンドルを回すと、尾びれが左右に動きます。

ほかに「キツツキ」もあり、5種類から会場や年齢に合わせて選べます。部品はCoreShiftが事前に人数分を用意し、完成したおもちゃはそのまま持ち帰れます。

05Notes

このプログラムの留意事項

  • 参加者用の端末（スマートフォン・タブレット）は要相談です。個人のスマートフォンの持参は前提にしません。
  • 造形は1枚約15分かかります。全員分を時間内に仕上げるには、プリンターの台数と人数の調整が必要です。事前に試し刷りで造形時間を確かめます。
  • 3Dプリンターの高温部・可動部に子どもが触れないよう、見学の範囲を決めます。
