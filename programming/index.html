01micro:bit

micro:bit でできること

LED・ボタン・傾きセンサーなどがついた小さなコンピューターです。書いたプログラムで、光らせる・反応する・数える、といった動きを作れます。

  • ブロックから始める

    ブロックを並べるだけで、すぐに動くプログラムが作れます。

  • 文字のコードへ

    慣れてきたら、同じプログラムを JavaScript や Python で書いてみます。

  • 3Dプリンターと組み合わせる

    自分で設計したケースや部品と組み合わせた作品づくりも考えています。3Dプリンターへ
