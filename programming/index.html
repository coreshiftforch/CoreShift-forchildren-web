プログラミング

準備中

手のひらサイズのコンピューター「micro:bit」を使って、自分で書いたプログラムでモノを動かす体験を準備しています。

01Purpose

目的：プログラミング的思考を身につける

コンピューターは、書かれたとおりにしか動きません。「順番・くり返し・条件分岐」を組み合わせて、思いどおりに動かす考え方（小学校で学ぶ「プログラミング的思考」）を、micro:bit を動かしながら身につけます。

  1. 順番

    決めた順に動く

  2. くり返し

    同じ動きを何回も

  3. 条件分岐

    「もし〜なら」で動きを変える

02micro:bit

micro:bit でできること

LED・ボタン・傾きセンサーなどがついた小さなコンピューターです。書いたプログラムで、光らせる・反応する・数える、といった動きを作れます。

  1. ブロックから始める

    ブロックを並べるだけで動く

  2. 文字のコードへ

    慣れたら JavaScript や Python で

  3. 3Dプリンターと組み合わせる

    自分で設計したケースに入れる
