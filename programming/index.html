Technology

プログラミング

準備中

micro:bit GO を使って、自分で書いたプログラムでモノを動かす体験会を準備しています。ブロックから始めて、慣れたら JavaScript や Python へ。小学生から中高生まで、同じ教材で段階的に学べる内容です。

01Can do

できること

教材は micro:bit GO。手のひらサイズのコンピューターで、LED・ボタン・傾きセンサーなどを使ったプログラムを作ります。

  • ブロックから始める

    MakeCode のブロックを並べるだけで、すぐに動くプログラムが作れます。

  • JavaScript・Pythonへ

    慣れてきたら、同じプログラムを文字のコードで書いてみます。

  • 学年に合わせて段階的に

    小学生から中高生まで、同じ教材でレベルを上げていけます。

02With 3D printing

3Dプリンターと組み合わせる

自分で設計したケースや部品と micro:bit を組み合わせた作品づくりを準備しています。

  • LEDで名前が流れる名札

    自分で設計したケースに入れて、名前を表示します。

  • 傾けると表情が変わる置物

    傾きセンサーを使って、LEDの顔を切り替えます。

  • 振ると数が出るサイコロ

    振ったことを検知して、1〜6の数を表示します。
